## Minha Pagina

Uma página simples desenvolvida em HTML, CSS e JavaScript para demonstrar uma interação básica com o usuário: acender e apagar uma lâmpada na interface.

## Descrição

Esta página foi criada como uma pequena demonstração de frontend web, com:

- um título principal;
- um texto explicativo;
- um elemento visual representando uma lâmpada;
- um botão para ligar/desligar a luz;
- mensagem de status que muda conforme o estado da lâmpada;
- estilo visual com tema escuro e alternância para um tema claro ao acender.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Como visualizar

1. Abra o arquivo `index.html` em um navegador.
2. Clique no botão `Ligar`.
3. A lâmpada será acesa e o fundo da página mudará de cor.
4. Clique novamente para desligar.

## Estrutura do projeto

- `index.html` — estrutura da página
- `estilo.css` — estilos visuais
- `script.js` — lógica da interação da lâmpada

## Objetivo

Este projeto serve como exemplo inicial para quem está começando no desenvolvimento web e quer aprender a manipular elementos da página com JavaScript.
